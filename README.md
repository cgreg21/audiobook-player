# Audiobook Player (NativeScript + Angular)

Lecteur de livres audio hors-ligne, sans serveur, pour fichiers MP3 locaux.

## Plan de MVP
1. Projet NativeScript + Angular, interface en français
2. Import de dossiers MP3 avec permission persistante
3. Bibliothèque locale et progression de lecture persistées en SQLite
4. Lecture audio avec ExoPlayer sur Android
5. Lecture en arrière-plan avec notification et commandes Now Playing
6. Podcasts Apple : recherche, abonnement (flux = livre, épisodes = chapitres) et téléchargement pour écoute hors ligne

Les signets et le réglage de vitesse sont hors périmètre du MVP.

## Lancer
```
ns run android
```
