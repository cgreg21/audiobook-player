# Audiobook Player (NativeScript + Angular)

Lecteur de livres audio hors-ligne, sans serveur, pour fichiers MP3 locaux.

## Plan de MVP
1. Projet NS + Angular, i18n (fr/en/es/de/ar, RTL)
2. Import (sélecteur de fichiers, copie en stockage privé)
3. SQLite : livres, chapitres, progression, signets
4. Lecteur ExoPlayer (Android) / AVPlayer (iOS) : reprise, vitesse
5. Service d'arrière-plan, notification / Now Playing
6. Minuteur de sommeil, signets
7. Import de dossier (permission persistante)

## Lancer
```
ns run android
ns run ios
```
